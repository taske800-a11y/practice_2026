# Журнал проекта Dark Machine

## Этап 1 — Старт и организация

- Зарегистрирован Git-репозиторий проекта на GitHub
- Участники команды освоили базовые команды Git: клонирование, коммиты, ветки, пуши
- Определена и закреплена структура директорий репозитория
- Выбран игровой движок Godot 4 в качестве основной платформы разработки
- Распределены роли внутри команды

---

## Этап 2 — Концепция и документация

- Сформулирована центральная игровая концепция и прописан Game Design Document (GDD)
- Детально описан игровой мир: завод, его уровни, фракции и история
- Спроектирована система прогрессии персонажа с двумя альтернативными путями
- Подготовлен первый блок документации в формате Markdown
- Проработаны первые наброски боевой системы и механик передвижения

---

## Этап 3 — Сайт и визуальные материалы

- Создан статический сайт проекта на HTML и CSS
- Реализованы страницы: главная, «О проекте», «Участники», «Журнал», «Ресурсы»
- Добавлены графические элементы и анимации в интерфейс
- Подготовлен отчёт по практике в соответствии с установленным шаблоном

---

## Этап 4 — Доработка и финализация

- Проведена ревизия и дополнение всей проектной документации
- Внедрены графические материалы: схемы, иллюстрации, концепт-арт
- Сформирована финальная версия репозитория
- Скомпилирован итоговый отчёт по практике в форматах DOCX и PDF
- Материалы загружены в СДО
